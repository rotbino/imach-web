# iMach Design 6 — «دستیارِ صبور» (دیزاین نهایی)

نسخهٔ نهایی پس از چهار دیزاین (R1–R4) و **دو دور بازبینی مستقل** (نقد ChatGPT روی پرامپت D5). این پکیج، دیزاین مرجع برای فاز تکمیل و مهاجرت به Next.js است.

## جوهر طرح

> ابزاری مالکانه که شبکه را در سکوت می‌سازد؛ وقتی نتیجهٔ واقعی آماده شد با زبان «برایت پیدا کردیم» روشنش می‌کند؛ و پول فقط در لحظه‌ای ظاهر می‌شود که کاربر تشنهٔ همان ارزش است.

## فرمول ترکیب (ارث چهار دیزاین)

| منبع | میراث |
|---|---|
| D1 | فرم‌های کامل — سه مسیر ورود داده (مرجع/اسکن/اکسل) در جای درست و بدون شلوغی |
| D2 | دو خانهٔ مستقل خرید/فروش + ۴ آیتم ناوبری + ساده‌ترین بار شناختی |
| D3 | کیفیت بصری و خلوت + احساس مالکیت + دعوت با متن آماده + استعلام شفاف |
| D4 | صدای دستیار + لحظهٔ «پیدا کردیم» + معماری آینه‌ای + نقاط پرداخت |

## تصمیم‌های کلیدی (پاسخ به بازبینی)

- **کاتالوگ از ناوبری خارج شد** — ابزار انتشار است نه job کاربر؛ زیر «کالاها» و شیت اشتراک
- **دستیار Dashboard نیست** — فقط «کار بعدیِ ارزشمند» (۱ اتفاق مهم + حداکثر ۲ کار)
- **۱۵ تجربه + شیت‌های درون‌جریان** — نه ۲۲ صفحهٔ مستقل
- **قانون سه‌سیگنالی**: فعال / مرتبط / بالقوه — سه زبان و سه وزن بصری جدا
- **دو ریتمِ پیدا کردن**: فوری یا «داریم می‌گردیم» + خبر بعدی
- **درآمد = فرضیهٔ آزمون‌پذیر** (اعتبار معرفی با هدیهٔ خوش‌آمد)؛ **جایگاه پولی در نتایج برای همیشه حذف شد**
- **ماشین حالت S0–S3**: حالت خالی/در حال رشد/روشن/دروازه — هر صفحه در چند حالت طراحی شده

## طرز مشاهده

- **دموی تعاملی:** `index.html` را باز کنید — ۱۹ تجربه قابل گشت‌وگذار، سوییچ خرید/فروش بالای اپ، و پیلِ «دمو» پایین-چپ برای جابه‌جایی بین حالت‌های S0 تا S3 (ابزار توسعه؛ در محصول واقعی نیست)
- **سند معماری:** `overview.html` — قوانین، ماتریس حالت‌ها، جریان طلایی، درآمد، گالری ۳۳ نما
- **پرامپت کامل:** `imach-d6-design-prompt.md` — بریف خودکفا برای هر AI/طراح
- **اسکرین‌شات‌ها:** پوشهٔ `png/` (۳۳ نما + overview)

# redesign-base-2 — UX فاینال روی دیزاین Base با رنگ واحد قرمز

این پوشهٔ طراحی، پاسخ به خواستهٔ مالک بعد از بازبینی redesign-final است:

> «طرح فعلی به دلم نمی‌شینه — رنگ‌ها و دیزاین و فرم‌ها و حس‌وحال بصری را از redesign-base بگیر،
> ولی نویگیشن و فرایندها و واژه‌ها و همهٔ امکانات بالغ را از redesign-final.»

## فرمول

| جنبه | منبع |
|---|---|
| UX · نویگیشن (آیتم‌ها + محل سویچر دستیارها) · فرایندها · واژه‌ها | **redesign-final** (v18 + فازهای ۱۰ تا ۱۳) |
| رنگ‌ها · دیزاین · فرم‌ها · حس‌وحال بصری | **redesign-base** (سفید گرم `#fcfbf8` · بوردر `#e7e4dc` · فلتِ ظریف) |
| رنگ دستیارها | **قرمز غلیظ دیوار `#a4272c`** — به‌جای دکمه‌های سیاه/گرافیتِ Base و فیروزه‌ایِ Final |

## تصمیم‌های کلیدی

1. **رنگ واحد دو دستیار** — خرید و فروش هردو از `--arm: #a4272c` تغذیه می‌کنند؛ تمایز فقط در
   آیکون و واژه است، نه رنگ. (خواستهٔ مالک: «لزومی به رنگ جدا نیست» — حس صنعتی و جدی مثل دیوار.)
   لوگوی iMach از قبل قرمز است (`#A62626`)؛ رنگ واحد با برند هم‌راستا شد.
2. **همهٔ امکانات بالغ فاینال حاضر است**: چت، پرموت (کمپین/بودجه)، کیف پول و شارژ،
   اشتراک‌گذاری لیست/کاتالوگ، رصد قیمت، آرشیو، تخفیف‌پله‌ای، جست‌وجو، نمای عمومی و… —
   تعداد صفحه‌ها و شیت‌ها عین redesign-final (۳۰ صفحه / ۲۸ شیت).
3. **واژه‌نامه مطابق فاینال** (هم‌نوا با بک‌اند و UI کد اصلی): «ذخیره کاتالوگ»، «دفتر خرید»،
   «پیشنهاد قیمت»، «کاتالوگ‌های مورد علاقه» و… .
4. **بک‌اند بدون هیچ تغییر** — این طرح فقط لایهٔ بصری را عوض می‌کند؛ ساختار داده، مسیرها و
   فیلدها همان است که اپ فعلی از بک‌اند می‌گیرد. پورت به اپ = فقط استایل و رنگ.
5. **زمردی** فقط برای معنای مثبت (رشد/موفقیت) ماند و **طلایی** فقط برای پرموت و ویژه.

## زبان دیزاین Base — لایهٔ ساختاری (فاز ۱۵)

نسخهٔ اول فقط توکن‌های رنگ را عوض می‌کرد (شکایت مالک: «همان فاینال با رنگ جدید است»).
فاز ۱۵ زبان دیزاین **ساختاری** Base را روی همهٔ کامپوننت‌های مشترک پیاده کرد —
HTML/JS و امکانات فاینال دست‌نخورده ماند، فقط CSS بازنویسی شد:

- **شل**: appbar ۵۶px با شیشه `rgba(255,255,255,.9)` · آواتار **دایره‌ای** (نه squircle) ·
  icon-btn شعاع ۱۰ · pagehead = subheader بیس (۵۴px + بکِ بی‌پس‌زمینه) ·
  **تب فعال بدون تینت** — فقط رنگ بازو + بولد + stroke ضخیم‌تر (عین Base).
- **کارت‌ها**: `.card` padding **۱۲** · row-card فشرده (۱۰/۱۲ + تیتر ۱۴ + زیرمتن ۱۱.۵) ·
  p-card شعاع **۱۶** با سایهٔ ظریف + placeholder ۱۰۸px + بدنه ۸/۱۰ · sup-card / rfq / sug همه ۱۲.
- **فرم‌ها (مهم‌ترین خواستهٔ مالک)**:
  - `.inp` = **۴۴px** با بوردر-strong و فونت ۱۴ — عین `.input` بیس (textarea ۷۶px/۱۱×۱۳).
  - لیبل ۱۲.۵ **تیره** (fg) بالای فیلد؛ hint = legend بیس (muted-bg بدون بوردر خط‌چین).
  - `.pillc` = pillchoice بیس: شعاع ۱۰ · فونت ۱۲.۵ · فعال = تینت + متنِ رنگ بازو.
  - `.form-cta` = **action-bar بیس**: نوار توپر `rgba(255,255,255,.97)` با **خطِ بالایی**
    (گرادیان شناور حذف شد) — با computed-style تست شد.
  - warn-note = callout بیس (کهربایی با بوردر #f2dfba) · gslot شعاع ۱۰ + قاب پرشده با بوردر و گرادیان ·
    inp-flex و intl-phone ارتفاع ۴۴/۵۰ با حلقهٔ فوکوس ۱۶٪ · checkrow بیس (ckb ۲۰/۶).
  - دکمه: `.btn` فونت **۱۴** · `.btn-lg` = CTA فرم‌های بیس: **۴۸px/فونت ۱۵** · btn-sm ۱۲.۵.
- **چیپ/بج**: چیپ ۱۲.۵ وزن معمولی با بوردر-strong (فعال: تینت + بوردر شفاف) · بج **گرد (999px)** ۱۰.۵.
- **سوییچ**: toggle بیس ۴۲×۲۴ · خاموش `#d8d4ca` · روشن = رنگ برند.
- **سرچ‌بار**: ۴۴px · بوردر-strong · فونت ۱۳ · placeholder #b0aca1.
- **شیت‌ها** (مخصوص فاینال): شعاع ۲۰ · ردیف‌های ۱۱/۱۲ با شعاع ۱۲ — هم‌زبان بیس.

## نحوهٔ ساخت

- `index.html` و موتور JS و همهٔ شیت‌ها = همان redesign-final (دست‌نخورده به‌جز ۳ لکهٔ رنگی inline).
- `css/style.css` دو لایه دارد:
  ۱) **توکن‌ها**: پالت خنثی گرم عین Base؛ `--primary` و خانوادهٔ `--teal` هر دو به قرمز غلیظ
     `#a4272c` / `#8f2226` / تینت `#f7e9e6`؛ دو انتخابگرِ بازو (buy/sell) به مقدار واحد؛
     ۵ گرادیان/rgba نارنجی hardcode به قرمز.
  ۲) **لایهٔ ساختاری Base** (فاز ۱۵): همهٔ کامپوننت‌های مشترک با مقادیر دقیق redesign-base
     (فهرست بالا) — نه فقط رنگ، بلکه ارتفاع/شعاع/تراکم/وزن فونت/الگوی اکشن‌بار.
- `assets/shots/*.png` (کلاژ گوشی لندینگ) از خودِ همین طرح بازتولید شد.
- `rapid-demo.html` با `tools/make-rapid-demo.py` بازتولید شد (۳۰ صفحه / ۲۸ شیت).

# redesign-base-2 — UX فاینال روی دیزاین Base با رنگ واحد قرمز

این پوشهٔ طراحی، پاسخ به خواستهٔ مالک بعد از بازبینی redesign-final است:

> «طرح فعلی به دلم نمی‌شینه — رنگ‌ها و دیزاین و فرم‌ها و حس‌وحال بصری را از redesign-base بگیر،
> ولی نویگیشن و فرایندها و واژه‌ها و همهٔ امکانات بالغ را از redesign-final.»

## فرمول

| جنبه | منبع |
|---|---|
| UX · نویگیشن (آیتم‌ها + محل سویچر دستیارها) · فرایندها · واژه‌ها | **redesign-final** (v18 + فازهای ۱۰ تا ۱۳) |
| رنگ‌ها · دیزاین · فرم‌ها · حس‌وحال بصری | **redesign-base** (سفید گرم `#fcfbf8` · بوردر `#e7e4dc` · فلتِ ظریف) |
| رنگ دستیارها | **قرمز غلیظ دیوار `#a4272c`** — به‌جای دکمه‌های سیاه/گرافیتِ Base و فیروزه‌ایِ Final |

## تصمیم‌های کلیدی

1. **رنگ واحد دو دستیار** — خرید و فروش هردو از `--arm: #a4272c` تغذیه می‌کنند؛ تمایز فقط در
   آیکون و واژه است، نه رنگ. (خواستهٔ مالک: «لزومی به رنگ جدا نیست» — حس صنعتی و جدی مثل دیوار.)
   لوگوی iMach از قبل قرمز است (`#A62626`)؛ رنگ واحد با برند هم‌راستا شد.
2. **همهٔ امکانات بالغ فاینال حاضر است**: چت، پرموت (کمپین/بودجه)، کیف پول و شارژ،
   اشتراک‌گذاری لیست/کاتالوگ، رصد قیمت، آرشیو، تخفیف‌پله‌ای، جست‌وجو، نمای عمومی و… —
   تعداد صفحه‌ها و شیت‌ها عین redesign-final (۳۰ صفحه / ۲۸ شیت).
3. **واژه‌نامه مطابق فاینال** (هم‌نوا با بک‌اند و UI کد اصلی): «ذخیره کاتالوگ»، «دفتر خرید»،
   «پیشنهاد قیمت»، «کاتالوگ‌های مورد علاقه» و… .
4. **بک‌اند بدون هیچ تغییر** — این طرح فقط لایهٔ بصری را عوض می‌کند؛ ساختار داده، مسیرها و
   فیلدها همان است که اپ فعلی از بک‌اند می‌گیرد. پورت به اپ = فقط استایل و رنگ.
5. **زمردی** فقط برای معنای مثبت (سوییچ روشن/رشد/موفقیت) ماند و **طلایی** فقط برای پرموت و ویژه.

## نحوهٔ ساخت

- `index.html` و موتور JS و همهٔ شیت‌ها = همان redesign-final (دست‌نخورده به‌جز ۳ لکهٔ رنگی inline).
- `css/style.css`: بلوک توکن‌ها بازنویسی شد — پالت خنثی گرم از redesign-base؛
  `--primary` و خانوادهٔ `--teal` هر دو به قرمز غلیظ `#a4272c` / `#8f2226` / تینت `#f7e9e6` نشستند؛
  دو انتخابگرِ بازو (buy/sell) به مقدار واحد رسیدند؛ ۵ گرادیان/rgba نارنجی hardcode به قرمز تبدیل شد.
- `assets/shots/*.png` (کلاژ گوشی لندینگ) از خودِ همین طرح بازتولید شد.
- `rapid-demo.html` با `tools/make-rapid-demo.py` بازتولید شد.

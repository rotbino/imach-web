# ۰۵ — مشخصات صفحات و قرارداد دادهٔ UI (Page Spec)

> **جایگاه:** این سند برای هر صفحهٔ پروتوتایپ redesign-base (۴۴ صفحهٔ موبایل + ۳ دسکتاپ + ۴۹ شیت + ۵ دیالوگ) تعریف می‌کند: هدف، نقاط ورود، داده‌های خوانده/نوشته‌شده و قواعد رفتاری. این قراردادِ UI↔داده است — مرجع «هر فیلد نمایشی منبع داده مشخصی دارد» و ابزار پایان‌دهی به نقص‌های پروتوتایپ.
> **نمادها:** شماره‌های C/M/S/N ارجاع به رجیستری شکاف سند ۰۷ هستند.

---

## ۰. مشترکات همهٔ صفحات

- **شل:** appbar (عنوان + زنگ اعلان ۲۷ + چشم پیش‌نمایش ۲۳ در بازوی خرید) + body + tabbar ۵ تبی.
- **فوتر فروش:** کارها(۲۰) · کاتالوک(۰۱) · درخواست‌ها(۰۵) · پیام‌ها(۱۸) · پروفایل(۰۷) — خانهٔ ۰۱.
- **فوتر خرید:** کارها(۳۹) · لیست خرید(۰۸) · کمپین‌ها(۳۱) · پیام‌ها(۱۸) · پروفایل(۱۴) — خانهٔ ۰۸.
- **دستیار خاموش:** پیل سوییچ از هدر حذف؛ گارد ناوبری به خانهٔ بازوی روشن؛ صفحات عمومی (۱۵/۱۶/۱۷/۴۳) و keep (۲۲/۴۲) مستثنا.
- **بازگشت:** راست‌گرد از استک با `DEFAULT_BACK`؛ زیرصفحه‌ها subheader دارند (۱۰، ۳۶، ۴۲، …).
- **اعداد:** فارسی با هزارگان؛ پول تومان نمایشی (÷۱۰ از minor ریال) — سند ۰۴ §۷.
- **حضور آنلاین (Presence):** چیپ سبز در ۱۳/۰۲/۲۳ + نقطهٔ سبز در ۱۸ — منبع `Business.lastSeenAt` (آستانه ۹۰s).

کارت کمپین (Promo type=CAMPAIGN فعال): هویت فروشنده + کالاها با قیمت خط‌خورده/بج تخفیف + روزهای مانده (endsAt) + camp-meta (حداقل خرید/شهر/آدرس/توضیح) + تماس/پیام/کاتالوک + legend شفافیت.

### ۳۳ — لیست مقایسه
گرید رتبه‌بندی‌شدهٔ قیمت‌های دنبال‌شدهٔ همان good: رتبه/فروشنده/شرایط/روند — **مرتب بر pricePerBaseMinor (C1)**، ارزان‌ترین قاب سبز + بج · رکورد→۰۲ · زیر لیست: «پیشنهاد تطابق iMach» (تبلیغی بالاتر از نتیجهٔ طبیعی — برچسب) · «استعلام گروهی از فروشندگان دنبال‌شده»→۱۲ · «تأمین‌کنندگان دیگر این کالا»→۰۹.

### ۳۴ — افزودن کالا به لیست خرید
جستجوی Good + پیشنهادی‌ها + «کالای جدید بساز» (GoodCreation PROVISIONAL) → «چقدر و چه دوره‌ای؟» استپر+دوره (WEEKLY/…) → WatchedGood → ۰۸.

### ۳۶ — پیشنهادات درخواست (زیرصفحهٔ ۱۱)
جزئیات درخواست + سورت چیپی (بهترین آیمچ/ارزان‌ترین/نزدیک‌ترین/جدیدترین — فرمول سند ۰۴ §۵) + کارت پیشنهاد (شهر/هم‌شهری/خرید قبلی/زمان/قیمت+واحد) → sheet-offerview (قیمت واحد/مجموع برای مقدار درخواست/حداقل/اعتبار/شرایط/توضیح + تماس/پیام/کاتالوک) + متوقف/بایگانی زنده + «دوباره درخواست بده». منبع: Offerهای همان rfqGroupId.

### ۳۷ — بازخورد خرید / ۴۰ — راهنمای دستیار خرید
FeedbackPost(kind=FEEDBACK, arm=BUY) + VideoLesson(arm=BUY) + QUESTION.

### ۳۹ — کارها (خرید)
آینهٔ ۲۰ با محتوای خریدار: «نیاز به پاسخ تو» (پیشنهادهای رسیده → ۳۶) · «کارهای سیستم» (لیستت را کامل کن/اعلان‌ها روشن نیست) · «یادآوری‌ها» (قیمت به هدف رسید →۳۳ · پیام خوانده‌نشده →۱۸).

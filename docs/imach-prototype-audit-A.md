## ۲) A3 — نقطه‌های کور و نیمه‌کاره‌ها

1. **P-2 (نرمال‌سازی واحد تابلو) — عمدتاً بسته است:** v5 آن را اجرا کرده: `unit-note` («مقایسه بر پایهٔ کیلوگرم») + `pack-line` (قیمت هر بسته) + واحد در خط قیمت. 🔴 باقی‌مانده: خودِ `unit-note` با **۹.۵px** عملاً ناخواناست — در فاز B به ۱۱px اصلاح می‌شود (نه ثابت، برچسب تصمیم).
2. **ناسازگاری عدد دیتای دمو:** تابلوی برنج = ۴ کارت + «+۳ دیگر» = **۷ تأمین‌کننده**، ولی همه‌جا گفته شده «۶ نفر» (pagehead تابلو، ردیف لیست خرید، دکمهٔ buy-item، متن پایانی boardMore/rfqMore). → فاز C یکدست می‌شود به ۷.
3. **شمار اعلان ناسازگار:** بج زنگ = ۲ ولی ۴ نقطهٔ خوانده‌نشده در شیت. → فاز C هر دو = ۴.
4. **مقصد اشتباه اعلان خریدار:** «پیشنهاد جدید برای روغن ۱۶ کیلویی» به `sc-sell-requests` می‌رود (سمت فروشنده!) — این اعلانِ خریدار است و باید به `sc-offers` برود. (C1-4 همین‌جا بسته می‌شود.)
5. **۳ شیت بدون دکمهٔ بستن:** `sheet-rates` · `sheet-call` · `sheet-cust-type` (anatomy شیت: Primary + Secondary-close). → فاز D.
6. **ترجیح شرایط پرداخت در فرم پاسخ:** پیش‌فرض «نقدی» است در حالی که تنظیمات فروشگاه می‌گوید «عندالتحویل». → فاز C (C1-1).
7. **Drift مستندات:** overview.html «۲۷ صفحه/۱۸ شیت» (واقعیت ۳۰/۲۴) · README ردیف zip غایب. → فاز H.
8. **گپ‌های a11y:** `prefers-reduced-motion` غایب · focus-visible فقط دسکتاپ · هیت‌اریای چند دکمه < ۴۴px (icon-btn ۳۶ · gear-btn ۲۸ · icon-follow ۳۸). → فاز B.
9. **دکمهٔ مردهٔ جست‌وجوی کاتالوگ فروشنده:** فقط toast می‌دهد؛ الگوی واحد جست‌وجو (C1-6) به sc-search وصل می‌شود.

- **باگ واقعیِ نهفته در esc()**: `esc(نام‌ها + join('<span>'))` نشانهٔ
  جداساز را هم escape می‌کرد — «·» به‌شکل متنِ خام `&lt;span…&gt;` روی

  `<span` در برگ‌ها) آن را قطعی کرد. درس: escape روی «داده» اعمال شود
  نه روی «قالب متصل‌شده».
- کانبانِ ساختهٔ JS (نه HTML پخته): show() هر بار قالب خام را
  می‌ریزد → موبایل بایت‌به‌بایت دست‌نخورده می‌ماند و QA موبایلش
  خودکار سبز می‌شود؛ :has(.row:not([hidden]))) ستون خالی را زنده
  پنهان می‌کند بدون دخالت JS سینک.

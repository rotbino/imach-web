## اصول طراحی

1. **اول ابزار، بعد شبکه** — ارزش اصلی از مدیریت خرید و فروش می‌آید
2. **شبکهٔ خصوصی، پایه است** — هر کسب‌وکار شبکهٔ خودش را دارد
3. **استعلام ≠ سفارش** — دو فرایند کاملاً جدا
4. **صنف ≠ گروه مشتری** — صنف فیلتر، گروه تخفیف
5. **کاتالوگ خصوصی یا عمومی** — انتخاب کاربر

## توسعه

برای افزودن صفحهٔ جدید:
1. یک `<section class="screen" id="s-xxx">` در `index.html` اضافه کنید
2. در تب‌بار یا دکمه، `data-go="s-xxx"` بگذارید
3. اگر به شیت نیاز دارد، `<div class="sheet" id="sheet-xxx">` بسازید
4. برای باز کردن شیت: `data-sheet="sheet-xxx"`

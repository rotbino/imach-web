# mvp-final — نسخهٔ نهایی MVP آی‌مچ (آمادهٔ پیاده‌سازی)

اسکلت و سادگیِ خیره‌کننده از **mvp-design**؛ پوست و جزئیات فاخر (توکن‌ها، سایه‌ها، هدرهای شیشه‌ای، لندینگ و فرم‌های auth) از **redesign-base**. نه چیز اضافه، نه چیز کم.

## نسبت به mvp-design دقیقاً چه چیزی تغییر کرد؟

**۶ قابلیت افزوده (توافق مالک):**

| # | قابلیت | کجا |
|---|--------|-----|
| ۱ | **تیپ و صنف موقع ثبت‌نام** (خریدارم/فروشنده‌ام/هر دو + صنف) | گام دوم ثبت‌نام — الگوی scr-16 بیس |
| ۲ | **«قیمت‌های من را کی ببیند»** — همه یا صنف‌های خاص | پروفایل → شیت تنظیمات کاتالوگ؛ نمونهٔ زنده: b3 فقط سوپرمارکت و خواروبار |
| ۳ | **اعلان کاهش قیمت (واقعی)** — قول «خبردار می‌شی» اجرا شد | زنگ در اپ‌بار + صفحهٔ اعلان‌ها؛ مکانیزم: مقایسهٔ updatedAt/prevPrice با آخرین بازدید |
| ۴ | **مهر تازگی قیمت** | چیپ «امروز/دیروز/X روز پیش» روی همهٔ ردیف‌ها؛ >۷ روز کهربایی |
| ۵ | **راه خروج از صفحات خالی** | تابلوی بدون فروشنده → «خبردار شو»؛ جستجوی بی‌نتیجه → درخواست افزودن کالا |
| ۶ | **حذف داده‌های قلابی** | «پرتکرار در صنف شما» حالا از آگهی‌های هم‌صنف‌ها محاسبه می‌شود؛ چیپ‌های ثابت −۵٪/+۲٪ → استپر عددی ۰٫۵٪ (الگوی فاز ۳۹ بیس) با پیش‌نمایش زنده |

**ارتقای ظاهر به سطح بیس:** لندینگ با هیرو تینت نارنجی + کلاژ عکس + مزایای شماره‌دار + CTA گرادیانی + نوار چسبان؛ ورود/ثبت‌نام با لوگوی وسط، کارت سایه‌دار، شمارهٔ تأییدشدهٔ سبز، مینی‌پروگرس، تایمر شمارش‌معکوس واقعی؛ اپ‌بار و تب‌بار شیشه‌ای (blur)؛ رنگِ بازوی فعال (فروش=نارنجی / خرید=سنگی)؛ سایه و شعاع‌های استاندارد.

**قرارداد واحد مقایسه (توافق مالک):**
- کالای مرجعِ برند‌دار بسته‌بندی‌شده → **هر واحد مصرف‌کننده** (روغن گلان ۲٫۵ لیتری: هر عدد؛ برنج معطر گیلان: هر کیسه). دو اندازهٔ یک برند = دو کالای مرجع جدا.
- فله / بی‌برند → واحد عمومی مصرف‌کننده (هر کیلو / هر لیتر / هر ۱۰۰ گرم).
- مدل داده: `Ref.perUnit` (مقدار واحد پایه در هر واحد مصرف‌کننده) + `Ref.cmp`؛ لیستینگِ برند‌دار `qty` = تعداد واحد مصرف‌کننده در بستهٔ فروش (کارتن ۶ عددی → ۶). تابلوی گود، لیستینگ‌های برند‌دار را با `perUnit` به واحد عمومی تبدیل می‌کند.

## چه چیزهایی عمداً نیست (قفسهٔ فاز ۲)
قیمت پلکانی، گروه مشتری و تخفیف همکار، آپلود اکسل، RFQ و پیشنهاد قیمت، چت داخلی، نظرات/امتیاز، کمپین و تبلیغ، کیف پول، استپر داخل فرم کالای منفرد (فاز ۴۰ بیس)، و **دیدن خریدارانِ یک کالا توسط فروشنده** — فقط وقتی خود خریدار درخواست بدهد.

## اجرا
`index.html` را باز کنید (بدون بیلد، بدون وابستگی). حساب نمونه: شمارهٔ پیش‌فرض + هر کد ۴ رقمی. شمارهٔ دیگر = کاربر تازه‌وارد.

## QA
- `node tools/qa.mjs` — ۶۱ چک رفتاری (لندینگ/ورود/ثبت‌نام/اعلان/واحد مقایسه/دید قیمت/استپر/پرتکرار/کاربر تازه) — همه پاس، صفر خطای کنسول.
- `node tools/shots.mjs` — ۱۷ اسکرین‌شات؛ داوری VLM: بدون هم‌پوشانی، میانگین ~۹/۱۰.

## ساختار
```
index.html        پوسته + اسپرایت آیکون‌ها (۲۹ آیکون)
css/app.css       سیستم طراحی (توکن‌های بیس + لندینگ + auth + استپر + اعلان + قفل صنف)
js/data.js        دادهٔ نمایشی: صنف‌ها، priceFor، Ref.perUnit/cmp، گلان ۲٫۵ لیتری (جدید)
js/app.js         اپ تک‌فایلی (هش-روتینگ، localStorage، ۱۲ مسیر)
tools/qa.mjs      QA رفتاری پلی‌رایت
tools/shots.mjs   اسکرین‌شات‌ها
shots/            خروجی تصاویر
```

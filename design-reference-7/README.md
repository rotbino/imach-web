# iMach Design 7 — «دستیارِ صبور + موتور رشد»

نسخهٔ هفتم، پاسخ مستقیم به نقد مالک روی D6 است. D6 معماری درست داشت (دو خانهٔ مستقل، ماشین حالت S0–S3، قانون نور) اما سه اشتباه راهبردی مرتکب شده بود: سوییچرِ سریعِ بالای صفحه، وعدهٔ «پیدا می‌کنیم» در روز اول، و پراکندگیِ بی‌هدفِ اشتراک‌گذاری. R7 این سه را ریشه‌ای درمان می‌کند و موتور رشد D3 را — کاتالوگ به‌عنوان دستاورد، دعوت به‌عنوان اهرم، اعتبار معرفی به‌عنوان پاداش — به قلب تجربه برمی‌گرداند.

## جوهر طرح

> روز اول هیچ وعده‌ای نیست. کاربر کالایش را ثبت می‌کند، کاتالوگش زنده می‌شود، و مشتری‌های خودش را با لینک، QR و دعوت وارد می‌کند. «پیدا کردیم» پاداشِ صبر است، نه وعدهٔ روز اول.

## چهار اصلاح ریشه‌ای (پاسخ به نقد مالک روی D6)

| نقد مالک | اصلاح R7 |
|---|---|
| سوییچر سریعِ بالای اپ اشتباه است — مدال قبلی بهتر بود | سوییچر حذف شد؛ پیل کوچک «دستیار خرید ›» فقط **شیت جابه‌جایی** را باز می‌کند: دو ردیف با پیش‌نمایش کارِ در انتظار هر دستیار + تیک فعال — تعویض عمدی و آگاهانه |
| وعدهٔ زودهنگام «ما برات پیدا می‌کنیم»، انگیزهٔ آوردن همراهان را تضعیف می‌کند | همهٔ وعده‌ها از آنبوردینگ و S0 حذف شد؛ چرخهٔ روز اول: **ثبت کالا ← کاتالوگ آماده ← مشتری‌هایت را بیاور**؛ آمار جعلی «۳ برابر» هم حذف شد |
| اشتراک‌گذاری پراکنده و بی‌هدف؛ کاتالوگ از روایت حذف شده | **یک حلقه، یک خانه:** کارت رشدِ حالت‌آگاه در خانهٔ هر دستیار + لحظهٔ طلایی اشتراک بلافاصله بعد از ثبت + شیت اشتراک کامل D3 (واتساپ/تلگرام/کپی/QR سرداب) + پاداش «+۱ اعتبار معرفی» |
| فونت IRANSans اعمال نشده و فرم‌ها زشت شده‌اند | فایل‌های واقعی **IRANSansWeb.woff / IRANSansWeb_Bold.woff2** داخل بسته (قبلاً پوشهٔ fonts جا می‌ماند) + پولیش فرم: ارتفاع ۴۶px، فوکوس نرم، فلش سفارشی سلکت |

## حلقهٔ رشد — قلب R7

```
ثبت کالا ← کاتالوک آماده ← ارسال لینک (واتساپ/تلگرام/QR روی سرداب)
← ورود مشتری بدون ثبت‌نام ← اتصال مستقیم ← +۱ اعتبار معرفی
← شبکهٔ روشن: «پیدا کردیم» فقط وقتی واقعی است ← دروازه (اعتبار = دسترسی)
```

بازخورد مرئی حلقه را می‌بندد: نشان «از دعوت تو» روی خریداران/تأمین‌کنندگان + تاریخچهٔ کیف پول («دعوت: سوپرمارکت آفتاب +۱ اعتبار») + مسیر رایگانِ دروازه («خودت دعوتش کن»).

## طرز مشاهده

- **دموی تعاملی:** `index.html` — ۲۰ تجربه × ۴ حالت؛ پیل «دمو» پایین-چپِ صفحه بین S0 تا S3 جابه‌جا می‌کند (ابزار توسعه؛ در محصول واقعی نیست)
- **پارامترهای URL:** `?st=s0..s3` + `&sheet=switch|share|invite|why|gate|excel|scan` + `&qr=1` + `&nudge=found|search` + `&tab=found` + `&sugg=1`
- **سند معماری:** `overview.html` — ۱۱ بخش: پاسخ به نقد، حلقهٔ رشد ۸-گرهی، سوییچ آهسته، ماشین حالت، جریان طلایی، درآمد، گالری ۳۶ نما
- **بستهٔ کامل:** `imatch-redesign-7.zip` (~۱۰MB — فونت و لوگو داخلش تأیید شده)
- **اسکرین‌شات‌ها:** پوشهٔ `png/` (۳۷ نما + overview)

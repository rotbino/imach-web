آی‌مچ دقیقاً چیست؟
بستری برای اتصال نیاز خریداران به تأمین‌کننده‌های مناسب — کاتالوگ فروش و لیست خرید، ساده‌ترین راه برای شروع کار با آی‌مچ هستند.
برای استفاده باید برنامه نصب کنم؟
نه. کاتالوگ‌ها و صفحه‌های خرید از طریق لینک قابل مشاهده‌اند؛ مشتری یا تأمین‌کننده بدون نصب برنامه هم می‌تواند ببیند.
آی‌مچ فقط یک ابزار ساخت کاتالوگ است؟
نه. کاتالوگ و لیست خرید فقط نقطه شروع هستند. هدف آی‌مچ این است که نیاز خریدار هر کالا را با اطلاعات تأمین‌کنندگان مناسب همان کالا نزدیک کند.

# دیزاین رفرنس ۲ — iMatch UX Redesign

> بستهٔ مرجع طراحی UX (۲ اکتبر ۲۰۲۶) — **تأییدشده توسط کارفرما**

این پوشه یک **مرجع طراحی ایستا** است و بخشی از بیلد Next.js نیست.
هدف: حفظ نسخهٔ تأییدشدهٔ ریدیزاین UX پیش از انتقال به کد اصلی.

## اصل حاکم

**Reduce cognitive load, not capability** — هیچ قابلیتی حذف نشده؛
فقط زمان و جای نمایشش مدیریت می‌شود (Progressive Disclosure).

## طراح ساختار

- آنبوردینگ: یک سؤال «الان بیشتر برای چی اومدی؟» → خرید دارم / فروش دارم
- دستیار فروش (پایین): کاتالوگ من | درخواست‌های قیمت | پروفایل
- دستیار خرید (پایین): لیست خرید | تأمین‌کنندگان | پیشنهادها | پروفایل
- سوییچ دستیار: در هدر، کم‌رنگ (`خرید ▾`)
- تابلوی تأمین: خارج از ناوبری اصلی — از دلِ کالای لیست باز می‌شود
- کاتالوگ: Storefront + مدیریت ظریف (badge / bottom sheet)
- نمایش ویژه: بج شفاف؛ رتبهٔ مرتبط‌سازی مستقل از پرداخت
- هوش مصنوعی: پشت تجربه («برای تو پیدا کردیم»)

## طراح مشاهده

`index.html` را در مرورگر باز کنید — نمونهٔ تعاملی کامل (۱۶ صفحه، آفلاین).
`overview.html` — سند مرور طرح و نگاشت قواعد بریف به صفحات.
`png/` — ۱۷ اسکرین‌شات.

## وضعیت

- ✅ تأیید کارفرما (۲۰۲۶-۱۰-۰۲)
- ⏳ انتقال مرحله‌به‌مرحله به `app/` در شاخهٔ اصلی — انجام نشده
